# Wiki CheckIn

Tyto stránky jsou připravené jako obsah GitHub wiki. Obrázky jsou v `img/` a odkazují se
relativně, takže se v repozitáři zobrazí přímo.

Publikace do wiki: na GitHubu otevřete záložku **Wiki**, založte první stránku a zkopírujte
obsah jednotlivých `.md` souborů. Obrázky nahrajte přes rozhraní wiki, nebo je nechte v repozitáři
a odkazujte je přes `https://github.com/pbruha/CheckIn/raw/claude/attendance-app-design-54x3yk/docs/wiki/img/…`.

Obsah odpovídá verzi aplikace s limitem 6 absencí (`ABSENCE_LIMIT=6`).
